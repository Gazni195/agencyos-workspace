# AgencyOS Workspace

Create the initial AgencyOS UI foundation for a marketing company operations platform. IMPORTANT NAVIGATION STRUCTURE: use Employees as a parent module in the main sidebar. Do NOT put Attendance, Leaves, Payroll, Performance, or Employee Documents as separate top-level sidebar items. Inside Employees, create a nested employee workspace with tabs/submodules: Directory, Attendance, Leave Management, Payroll, Performance, Documents, Timesheets, and Employee Settings. Main top-level sidebar should be: Dashboard, Clients, Leads, Projects, Tasks, Employees, Finance, Reports, Inbox, Assets, Settings. Build a polished modern SaaS interface with a dark navy sidebar, purple primary accent, rounded cards, KPI widgets, charts, tables, filters, search, status badges, and responsive layouts. Create realistic sample data and screens for: Owner Dashboard, Employee Directory, Employee Profile, Attendance, Leave Management, Payroll, Performance, Documents, and Timesheets. Keep the architecture modular and ready for later Supabase integration.
